# Task 11: JWT Decoder & Validator Tool

## Overview

Build a JWT (JSON Web Token) decoder and validator that decodes JWT tokens, displays header and payload, validates signatures, and shows expiration status.

## Market Research

### Why This Tool?
- **High Demand**: Developers constantly need to debug JWT tokens
- **SEO Value**: "jwt decoder", "jwt validator", "decode jwt", "jwt token decoder"
- **Developer Pain Point**: No easy way to inspect JWT tokens
- **Security Tool**: Essential for debugging authentication issues

### Reference Tools
- **jwt.io**: https://jwt.io/ (Industry standard)
- **JWT Decoder**: Various online tools

### Competitive Analysis
- jwt.io is the gold standard but can be improved
- Opportunity: Better UI/UX
- Opportunity: More validation features
- Opportunity: Token history

## UI/UX Requirements

- Input field for JWT token
- Display decoded header and payload
- Show expiration status
- Validate signature (if secret provided)
- Copy decoded values
- Token history (localStorage)

## Technical Requirements

- Decode JWT header and payload
- Base64 URL decoding
- JSON formatting
- Expiration checking
- Signature validation (optional, requires secret)

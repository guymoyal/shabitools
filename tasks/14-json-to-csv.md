# Task 14: JSON to CSV Converter Tool

## Overview

Build a JSON to CSV converter that converts JSON arrays to CSV format with customizable delimiter and header options.

## UI/UX Requirements

- JSON input editor
- CSV output display
- Delimiter selection (comma, semicolon, tab)
- Header row option
- Download CSV button

## Technical Requirements

- JSON array parsing
- CSV generation
- Custom delimiter support
- Header row handling
- Download functionality

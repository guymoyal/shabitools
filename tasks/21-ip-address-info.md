# Task 21: IP Address Info Tool

## Overview

Build an IP address information tool that shows geolocation, ISP, timezone, and other details for any IP address.

## Market Research

### Why This Tool?
- **Network Tool**: Useful for network debugging
- **SEO Value**: "ip address info", "ip lookup", "ip geolocation"
- **Security Tool**: Helps identify IP origins

## UI/UX Requirements

- IP address input
- Display geolocation info
- Show ISP and organization
- Timezone information
- Map visualization (optional)

## Technical Requirements

- IP geolocation API integration
- Data display and formatting
- Error handling
- Caching (optional)

## SEO & Content

- Title: "IP Address Info - IP Lookup & Geolocation"
- Description: "Get detailed information about any IP address including geolocation, ISP, timezone, and more."
- Keywords: "ip address info, ip lookup, ip geolocation, ip address checker"

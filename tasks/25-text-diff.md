# Task 25: Text Diff Tool

## Overview

Build a text diff tool that compares two text documents and highlights additions, deletions, and modifications with line-by-line comparison.

## Market Research

### Why This Tool?
- **Version Control**: Similar to git diff
- **SEO Value**: "text diff", "compare text", "text comparison"
- **Review Tool**: Essential for code and document review

## UI/UX Requirements

- Two text input areas
- Compare button
- Side-by-side diff view
- Line-by-line highlighting
- Statistics (added, removed, modified lines)

## Technical Requirements

- Text comparison algorithms
- Line-by-line diff
- Highlighting additions/deletions
- Statistics calculation
- Export diff (optional)

## SEO & Content

- Title: "Text Diff - Compare Text Documents Online"
- Description: "Compare two text documents and see differences. Line-by-line comparison with highlighting."
- Keywords: "text diff, compare text, text comparison, text differ, diff tool"

# Task 22: Email Validator Tool

## Overview

Build an email validator that validates email format, checks domain existence, and provides detailed validation reports.

## Market Research

### Why This Tool?
- **Common Need**: Email validation is frequently needed
- **SEO Value**: "email validator", "validate email", "email checker"
- **Form Validation**: Essential for form development

## UI/UX Requirements

- Email input field
- Validate button
- Validation results display
- Format validation
- Domain checking (optional, requires API)

## Technical Requirements

- Email format validation (regex)
- Domain validation (optional)
- MX record checking (optional)
- Real-time validation
- Detailed error messages

# Visual Diff Tool Data

This folder contains all content data for the Visual Page Compare tool.

## Files

- `overview.json` - Tool overview, features, use cases, and tips
- `instructions.json` - Step-by-step usage instructions and overlay mode descriptions
- `examples.json` - Practical usage examples

## Usage

These JSON files are imported and used in:
- `components/VisualDiff/Overview.tsx` - Overview component
- `app/tools/visual-diff/page.tsx` - Tool page (for metadata)
- Can be used in documentation and other places

## Editing

To update the tool content, simply edit the JSON files in this folder. The changes will automatically appear on the tool page.

# QR Code Generator Tool

## Overview

The QR Code Generator creates QR codes for URLs, text, WiFi credentials, email, phone numbers, and more with customization options and multiple download formats.

## Features

- **Multiple QR Code Types**: Generate QR codes for URLs, text, WiFi, email, phone, SMS, and more
- **Color Customization**: Customize foreground and background colors
- **Size Options**: Choose from small to large QR code sizes
- **Error Correction Levels**: Select error correction level (L, M, Q, H) for better scanning
- **Download Formats**: Download QR codes as PNG, SVG, or PDF
- **Live Preview**: See QR code update in real-time as you customize

## Use Cases

- Website QR codes for marketing
- WiFi sharing via QR code
- Contact information sharing
- Event tickets and passes
- Payment QR codes
- Product information codes

## Technical Details

- Uses qrcode.js library
- Supports multiple QR code formats
- Customizable error correction
- Real-time generation
- Multiple export formats

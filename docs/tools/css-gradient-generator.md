# CSS Gradient Generator Tool

## Overview

The CSS Gradient Generator tool allows you to create beautiful CSS gradients with an intuitive visual editor. Generate linear, radial, and conic gradients with custom colors, angles, and color stops, then export ready-to-use CSS code.

## Features

- **Visual Editor**: Interactive gradient editor with live preview
- **Color Picker**: Choose colors with hex, RGB, or HSL color pickers
- **Gradient Types**: Create linear, radial, and conic gradients
- **Angle Control**: Adjust gradient angle and direction precisely
- **Color Stops**: Add multiple color stops for complex gradients
- **CSS Export**: Copy ready-to-use CSS code instantly
- **Preview**: Real-time preview of gradient effects

## Use Cases

- Creating background gradients for websites
- Designing modern UI elements and components
- Generating gradient overlays for images
- Creating button styles and hover effects
- Design system development
- Hero section backgrounds

## Gradient Types

- **Linear Gradients**: Gradient flows in a straight line (top to bottom, left to right, diagonal)
- **Radial Gradients**: Gradient radiates from a center point outward
- **Conic Gradients**: Gradient rotates around a center point (like a pie chart)

## Technical Details

- Client-side processing (no server required)
- Supports all CSS gradient syntax
- Real-time preview and CSS generation
- Export CSS for background, background-image, or background property
- Compatible with all modern browsers
- No external dependencies

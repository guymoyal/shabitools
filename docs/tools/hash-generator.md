# Hash Generator Tool

## Overview

The Hash Generator creates MD5, SHA1, SHA256, SHA512 and other cryptographic hashes for data integrity verification and security purposes.

## Features

- **Multiple Algorithms**: Support for MD5, SHA1, SHA256, SHA512, and more
- **Text Input**: Generate hashes from text input
- **File Support**: Generate hashes from uploaded files
- **Copy Functionality**: Copy generated hashes easily
- **Comparison**: Compare multiple hashes
- **Real-time Generation**: Instant hash generation as you type

## Use Cases

- Data integrity verification
- Password hashing (for testing)
- File checksum generation
- Security testing
- Cryptographic operations
- Data validation

## Technical Details

- Uses Web Crypto API for secure hashing
- Supports multiple hash algorithms
- File hashing via FileReader API
- Client-side processing
- Secure hash generation

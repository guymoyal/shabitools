# JSON Formatter Tool

## Overview

The JSON Formatter tool is a comprehensive utility for working with JSON data. It allows developers to format, validate, minify, and visualize JSON structures with ease.

## Features

- **Format & Beautify**: Automatically format JSON with proper indentation
- **Validate**: Real-time validation with clear error messages and line numbers
- **Minify**: Remove whitespace to reduce file size
- **Syntax Highlighting**: Color-coded JSON syntax for easy reading
- **Tree View**: Visual tree structure with expand/collapse functionality
- **Error Detection**: Highlight syntax errors with helpful suggestions
- **Export Options**: Copy formatted JSON, download as file, or share via URL

## Use Cases

- Formatting API responses for readability
- Validating JSON data before using in code
- Minifying JSON files for production
- Debugging JSON syntax errors
- Learning JSON structure through visualization
- Preparing JSON for documentation

## Technical Details

- Client-side processing (no server required)
- Supports standard JSON format
- Handles nested objects and arrays
- Configurable indent size (2 or 4 spaces)
- Real-time validation using JavaScript JSON.parse()

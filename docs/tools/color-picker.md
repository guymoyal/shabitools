# Color Picker Tool

## Overview

The Color Picker allows you to pick colors and get hex, RGB, HSL codes instantly with color palette generation and export options for design workflows.

## Features

- **Color Selection**: Visual color picker with multiple input methods
- **Multiple Formats**: Get colors in hex, RGB, HSL formats
- **Palette Generation**: Create color palettes from selected colors
- **Copy Codes**: Copy color codes in any format
- **History**: Save recently used colors
- **Export Options**: Export palettes as JSON or CSS variables

## Use Cases

- Web design color selection
- Brand color palette creation
- CSS color code generation
- Design system development
- Color scheme exploration
- Accessibility color checking

## Technical Details

- HTML5 color input support
- Real-time format conversion
- Palette management
- Client-side processing
- Export to multiple formats

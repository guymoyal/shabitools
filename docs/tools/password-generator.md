# Password Generator Tool

## Overview

The Password Generator creates secure random passwords with customizable length, character types, and strength indicators for account security.

## Features

- **Customizable Length**: Set password length from 4 to 128 characters
- **Character Types**: Include uppercase, lowercase, numbers, and symbols
- **Strength Indicator**: Visual password strength feedback
- **Copy Functionality**: Easy copy to clipboard
- **Regeneration**: Generate new passwords instantly
- **Security**: Cryptographically secure random generation

## Use Cases

- Creating secure account passwords
- Generating API keys
- Creating secure tokens
- Password policy testing
- Security best practices
- Account setup assistance

## Technical Details

- Uses crypto.getRandomValues() for security
- Configurable character sets
- Strength calculation algorithm
- Client-side generation
- No server communication

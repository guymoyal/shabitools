# Base64 Encoder Tool

## Overview

The Base64 Encoder & Decoder is a versatile tool for encoding and decoding Base64 data. It supports text, images, and files with data URL generation and format validation.

## Features

- **Text Encoding/Decoding**: Encode and decode text to/from Base64 format
- **Image Encoding**: Upload images and convert them to Base64 data URLs
- **File Support**: Encode any file type to Base64 format
- **Data URL Generation**: Generate data URLs for embedding images in HTML/CSS
- **Image Preview**: Preview encoded images before using them
- **Format Validation**: Validate Base64 format and detect errors

## Use Cases

- Encoding text data for API transmission
- Embedding images in CSS or HTML
- Generating data URLs for small images
- API data encoding
- File encoding for storage or transmission
- Converting images to embeddable formats

## Technical Details

- Browser-based FileReader API for file handling
- Supports all file types
- Data URL generation for images
- UTF-8 encoding support for text
- Client-side processing (no server upload)

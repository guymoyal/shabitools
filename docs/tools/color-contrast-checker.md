# Color Contrast Checker Tool

## Overview

The Color Contrast Checker validates color contrast ratios for WCAG accessibility compliance, ensuring your designs are accessible to all users.

## Features

- **Contrast Ratio Calculation**: Calculate contrast ratio using WCAG formula
- **WCAG Compliance Check**: Check compliance with AA and AAA standards for normal and large text
- **Color Suggestions**: Get suggestions for accessible color combinations
- **Visual Preview**: See how text looks on background colors
- **Multiple Text Sizes**: Test normal and large text sizes
- **Accessibility Report**: Get detailed accessibility compliance report

## Use Cases

- Design validation for accessibility
- WCAG compliance checking
- Color selection for accessible designs
- UI/UX design review
- Accessibility audits

## Technical Details

- WCAG 2.1 contrast ratio formula
- Supports AA and AAA levels
- Real-time calculation
- Color picker integration
- Visual preview rendering

# CSS Minifier Tool

## Overview

The CSS Minifier & Optimizer reduces CSS file size by removing whitespace, comments, and optimizing selectors, improving website loading performance.

## Features

- **CSS Minification**: Remove whitespace and comments to reduce file size
- **Optimization**: Optimize CSS selectors and properties
- **Before/After Comparison**: See original and minified CSS side-by-side
- **Size Savings**: View exact size reduction and percentage saved
- **Validation**: Validate CSS syntax and catch errors
- **Export Options**: Copy minified CSS or download as file

## Use Cases

- Reducing CSS file size for production
- Performance optimization
- Production builds
- Learning optimization techniques
- Quick CSS minification

## Technical Details

- Client-side CSS minification
- Removes comments and whitespace
- Optimizes color values and zero units
- Calculates size savings
- No server processing required

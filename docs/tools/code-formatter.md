# Code Formatter Tool

## Overview

The Code Formatter supports multiple programming languages with customizable formatting options to ensure clean, readable code that follows style guidelines.

## Features

- **Multi-language Support**: Format code in JavaScript, TypeScript, Python, HTML, CSS, JSON, YAML, and more
- **Customizable Options**: Configure indent size, quote style, semicolons, and more
- **Syntax Highlighting**: Color-coded syntax for easy reading
- **Before/After Comparison**: See original and formatted code side-by-side
- **Copy/Download**: Copy formatted code or download as file
- **Share Functionality**: Share formatted code via URL

## Use Cases

- Formatting code for readability
- Code cleanup before committing
- Learning code style guidelines
- Preparing code for review
- Standardizing code format across projects

## Technical Details

- Language-specific formatting rules
- Configurable indent sizes (2 or 4 spaces)
- Basic formatting algorithms for each language
- Client-side processing
- Export to multiple file formats

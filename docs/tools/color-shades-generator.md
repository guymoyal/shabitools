# Color Shades Generator Tool

## Overview

The Color Shades Generator tool creates complete color palettes from a single base color. Generate shades (darker), tints (lighter), and tones (mixed with gray) to create consistent color schemes for design systems and UI components.

## Features

- **Shade Generation**: Generate darker shades of your base color
- **Tint Generation**: Generate lighter tints of your base color
- **Tone Generation**: Generate tones by mixing color with gray
- **Multiple Formats**: Export colors in hex, RGB, HSL, and CSS formats
- **Palette Export**: Export complete palette as JSON or CSS variables
- **Visual Preview**: See all color variations in a visual grid
- **Accessibility Check**: Check color contrast ratios

## Use Cases

- Creating design system color palettes
- Generating UI component colors (buttons, cards, etc.)
- Creating consistent color schemes for websites
- Design token generation for development
- Theme color development
- Brand color palette expansion

## Color Variations

- **Shades**: Darker versions created by adding black
- **Tints**: Lighter versions created by adding white
- **Tones**: Muted versions created by adding gray
- **Hue Variations**: Slight hue shifts for complementary colors

## Technical Details

- Client-side processing (no server required)
- HSL color space manipulation for accurate shades/tints
- Generates 5-10 color variations per palette
- Export in multiple formats (hex, RGB, HSL, CSS)
- Real-time preview of color palette
- Accessibility contrast checking

# Text Counter Tool

## Overview

The Text Counter provides detailed statistics about your text including word count, character count, sentence count, paragraph count, and more.

## Features

- **Word Count**: Count total words in your text
- **Character Count**: Count characters with and without spaces
- **Sentence Count**: Count sentences in your text
- **Paragraph Count**: Count paragraphs
- **Line Count**: Count total lines
- **Real-time Updates**: Statistics update as you type

## Use Cases

- Content writing and editing
- Meeting word count requirements
- Text analysis
- Writing productivity tracking
- Content length optimization
- SEO content planning

## Technical Details

- Real-time text analysis
- Multiple counting algorithms
- Client-side processing
- No data storage
- Instant statistics

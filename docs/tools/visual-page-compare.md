# Visual Page Compare Tool

## Overview

The Visual Page Compare tool allows developers and designers to visually compare two versions of a website side-by-side or using overlay modes for design testing and quality assurance.

## Features

- **Side-by-Side Comparison**: View two pages simultaneously
- **Overlay Modes**: Blend, onion skin, and overlay comparison modes
- **Viewport Presets**: Test at 375px, 768px, 1200px, or custom widths
- **Synchronized Scrolling**: Both iframes scroll together for easy comparison
- **Dark Mode**: Toggle between light and dark themes
- **Settings Panel**: Configure device height and check iframe embedding

## Use Cases

- Comparing staging vs production versions
- A/B testing visual changes
- Quality assurance testing
- Design review and approval
- Responsive design testing
- Visual regression testing

## Technical Details

- Uses iframes for page embedding
- Synchronized scrolling via JavaScript
- Handles X-Frame-Options restrictions
- Custom viewport width support
- Real-time mode switching

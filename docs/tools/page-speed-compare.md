# Page Speed Compare Tool

## Overview

The Page Speed Compare tool allows you to compare performance metrics between multiple URLs using Google PageSpeed Insights API, helping identify performance bottlenecks and optimization opportunities.

## Features

- **Performance Comparison**: Compare performance scores side-by-side for multiple URLs
- **Core Web Vitals Analysis**: Analyze LCP, FID, CLS, and other Core Web Vitals metrics
- **Mobile/Desktop Testing**: Test both mobile and desktop performance
- **Export Results**: Export comparison results as JSON or CSV
- **Optimization Recommendations**: Get suggestions for improving page performance

## Use Cases

- Staging vs Production comparison
- A/B testing performance
- Competitor analysis
- Performance monitoring
- Optimization tracking

## Technical Details

- Uses Google PageSpeed Insights API v5
- Requires API key (NEXT_PUBLIC_PAGESPEED_API_KEY)
- Supports mobile and desktop strategies
- Real-time metric calculation
- Error handling for API failures

# Regex Tester Tool

## Overview

The Regex Tester is an interactive tool for testing, debugging, and learning regular expressions. It provides real-time matching, visualization, and explanations to help developers master regex patterns.

## Features

- **Real-time Matching**: See matches update instantly as you type
- **Match Highlighting**: Visual highlighting of matches and captured groups
- **Pattern Explanation**: Plain English explanations of regex patterns
- **Pattern Library**: Access to common patterns (email, URL, phone, etc.)
- **Group Capture Display**: See all captured groups with positions
- **Flags Support**: Test with global, case-insensitive, multiline, and other flags
- **Error Handling**: Clear error messages for invalid patterns

## Use Cases

- Testing regex patterns before using in code
- Learning how regular expressions work
- Debugging complex regex patterns
- Validating input patterns
- Extracting data from text
- Understanding regex syntax through examples

## Technical Details

- Client-side JavaScript RegExp engine
- Supports all standard regex flags (g, i, m, s, u, y)
- Pattern library with pre-configured examples
- Real-time explanation generation
- Match position tracking

# UUID Generator Tool

## Overview

The UUID Generator creates RFC 4122 compliant UUIDs (Universally Unique Identifiers) for unique identifiers in databases, APIs, and distributed systems.

## Features

- **RFC 4122 Compliant**: Generates standard UUIDs (version 4)
- **Batch Generation**: Generate multiple UUIDs at once
- **Copy Functionality**: Copy individual or all UUIDs
- **Format Options**: Standard UUID format (8-4-4-4-12)
- **Unique Guarantee**: Cryptographically random UUIDs
- **Export Options**: Download UUIDs as text file

## Use Cases

- Database primary keys
- API request IDs
- Distributed system identifiers
- Session tokens
- Unique resource identifiers
- Testing and development

## Technical Details

- Uses crypto.randomUUID() API
- RFC 4122 version 4 compliant
- Cryptographically secure random generation
- Client-side generation
- No server required

# API Tester Tool

## Overview

The API Tester is a comprehensive REST API testing tool that allows developers to send HTTP requests, view responses, and debug APIs without installing additional software.

## Features

- **All HTTP Methods**: Support for GET, POST, PUT, DELETE, PATCH, HEAD, OPTIONS
- **Headers Editor**: Add and manage custom headers for requests
- **Query Parameters**: Build query parameters easily with key-value pairs
- **Request Body Editor**: Support for JSON, form-data, raw text, and URL-encoded bodies
- **Response Viewer**: View formatted responses with syntax highlighting
- **Request History**: Save and reuse previous requests
- **Code Generation**: Generate cURL and fetch code for your requests

## Use Cases

- Testing APIs during development
- Debugging API endpoints
- Learning API structures
- API documentation and examples
- Quick API health checks
- Exploring third-party APIs

## Technical Details

- Uses browser Fetch API
- CORS limitations may apply (noted in UI)
- Real-time request/response display
- Response time and size tracking
- Error handling with clear messages

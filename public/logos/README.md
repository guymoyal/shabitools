# Logo Options

## Available Logo Variants

### Logo 1: Classic Snail with Tools
- Snail with spiral shell
- Wrench and screwdriver tools
- Clean, simple design

### Logo 2: Snail with Gear Shell
- Snail with gear-shaped shell (represents tools/mechanics)
- Hammer and screwdriver tools
- More technical/mechanical feel

### Logo 3: Snail with Toolbox
- Snail with spiral shell
- Toolbox with wrench
- Professional tool-focused design

### Logo 4: Modern Snail with Multiple Tools
- Modern spiral design
- Multiple tools (wrench, screwdriver, hammer)
- Most comprehensive tool representation

## Usage

To change the logo variant, update the `logoVariant` prop in `app/layout.tsx`:

```tsx
<Header data={headerData} tools={toolsData} logoVariant={1} />
```

Available variants: `1`, `2`, `3`, or `4`

## Preview

Open `logo-preview.html` in your browser to see all logos side by side.
